# Blinkit Data Analysis

This is a data analysis project based on Blinkit grocery sales data.

I used SQL to explore the data and Power BI to create a dashboard and find useful insights from the sales data.

## Tools Used

- PostgreSQL
- Power BI
- Excel

## What I Analyzed

- Outlet type and outlet location
- Total sales
- Average sales
- Sales by item type
- Sales by outlet size
- Sales by fat content
- Highest selling items
- Missing values
- Items with sales above average

## SQL

I used PostgreSQL for the analysis.

Some of the queries I worked on include:

- Counting outlets
- Finding unique outlets
- Grouping sales by outlet type
- Finding average sales
- Finding the highest selling item
- Using CASE statements to categorize sales
- Checking NULL values

The SQL queries are available here:

`Blinkit_SQL_Analysis.sql`

## Power BI Dashboard

I created a Power BI dashboard to visualize the sales data and compare different outlets, item types and sales performance.

Power BI file:

`Blinkit_Sales_Dashboard.pbix`

## Files

- `Blinkit Grocery Data.csv` – Dataset
- `Blinkit_SQL_Analysis.sql` – SQL queries
- `Blinkit_Sales_Dashboard.pbix` – Power BI dashboard
- `Images/` – Dashboard images
- `blinkit.json` – Data file
- `background kpi.png` – Dashboard background

## Some Results

- Tier 3 outlets had the highest total sales among the three location types.
- Medium-sized outlets had the highest total sales by outlet size.
- Low Fat products had the highest total sales by fat content.
- The highest-selling item in my analysis was from the Canned category.
